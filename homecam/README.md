# กล้องในบ้าน (HomeCam) — Android

แอปดูกล้องวงจรปิดในบ้านแบบสด **ไม่ผ่านคลาวด์** ใช้ได้กับกล้องหลายยี่ห้อที่ต่อ Wi-Fi บ้าน
และรองรับ **RTSP** หรือ **ONVIF** เพิ่มกล้องได้ไม่จำกัด

## ติดตั้ง
1. ไปที่หน้า **Releases** ของ repo นี้ ดาวน์โหลด `homecam.apk` จาก release `homecam-v1.0.x` ล่าสุด
2. อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์/ตัวจัดการไฟล์
3. มือถือต้อง **ตั้งล็อกหน้าจอ** (PIN/รหัส/สแกนนิ้ว) ก่อน ไม่งั้นแอปจะไม่ยอมเปิด

## เพิ่มกล้อง
มือถือต้องต่อ Wi-Fi บ้านเดียวกับกล้อง แล้วกด **＋ เพิ่ม**

- **วิธีอัตโนมัติ (ONVIF):** กด "ค้นหากล้องใน Wi-Fi" → เลือกกล้อง → ใส่ชื่อผู้ใช้/รหัสผ่านกล้อง →
  "ดึงลิงก์อัตโนมัติ" → "ทดสอบ" → "บันทึก"
- **เลือกยี่ห้อ:** เลือกยี่ห้อ → ใส่ IP กล้อง (ดูได้ในแอปของกล้อง หรือหน้ารายชื่ออุปกรณ์ของเราเตอร์) → ชื่อผู้ใช้/รหัสผ่าน
- **วางลิงก์:** วาง `rtsp://user:pass@192.168.1.20:554/path` ลงช่อง IP ได้เลย

| ยี่ห้อ | ต้องทำในแอปกล้องก่อน |
|---|---|
| TP-Link Tapo / VIGI | ตั้งค่าขั้นสูง → **บัญชีกล้อง** (ใช้บัญชีนี้ ไม่ใช่บัญชี TP-Link) |
| Hikvision / HiLook | ใช้ admin + รหัสที่ตั้งตอนเปิดใช้งาน |
| EZVIZ | admin + Verification Code บนสติกเกอร์ บางรุ่นต้องเปิด RTSP/LAN Live View |
| Dahua / Imou | admin + Safety Code บนสติกเกอร์ (Imou) |
| Reolink | เปิด RTSP ในตั้งค่าเครือข่าย → พอร์ตขั้นสูง |
| Uniview, V380, Yoosee | มีค่าตั้งต้นในแอป บาง V380 ต้องเปิด RTSP ก่อน |
| อื่นๆ | ถ้ามี ONVIF/RTSP ใช้ได้ทั้งหมด |

> **ใช้ไม่ได้:** กล้องที่ล็อกให้ดูผ่านคลาวด์ของยี่ห้อเท่านั้น เช่น Xiaomi/Mi Home รุ่นทั่วไป
> และกล้องแบตเตอรี่ส่วนใหญ่ (ไม่เปิดสตรีมตลอดเวลา)

## ความปลอดภัย
- **ภาพไม่ออกนอกบ้าน:** มือถือดึงภาพจากกล้องตรงๆ ไม่มีเซิร์ฟเวอร์กลาง ไม่มี analytics
- **เชื่อมต่อได้เฉพาะเครือข่ายบ้าน:** ทุกที่อยู่ต้องเป็น IP ภายใน (192.168.x, 10.x, 172.16–31.x,
  100.64/10 สำหรับ Tailscale, IPv6 ULA) แอปตรวจ DNS ก่อนแล้วต่อด้วย IP ที่ตรวจแล้ว กันการส่งรหัสออกอินเทอร์เน็ต
- **รหัสผ่านเข้ารหัส AES-256-GCM** ด้วยกุญแจใน Android Keystore (TEE/StrongBox) ที่ดึงออกจากเครื่องไม่ได้
  และใช้ได้เฉพาะ 5 นาทีหลังสแกนนิ้ว/ใบหน้า/PIN — ต่อให้มีคนเข้าถึงไฟล์ของแอปได้ก็ถอดรหัสไม่ได้
- **ล็อกทันที** เมื่อออกจากแอป สลับแอป หรือปิดจอ และล้างข้อมูลที่ถอดรหัสแล้วออกจากหน่วยความจำ
- ถ้าเอาล็อกหน้าจอมือถือออก กุญแจจะถูกทำลายและข้อมูลกล้องถูกลบเพื่อความปลอดภัย
- ห้ามแคปหน้าจอ/อัดหน้าจอ ซ่อนภาพในหน้าสลับแอป ไม่สำรองข้อมูลขึ้นคลาวด์ กันการกดผ่านหน้าต่างซ้อน (overlay)
- ONVIF ใช้รหัสแบบ digest (WS-Security / HTTP Digest) ไม่ส่งรหัสผ่านเป็นข้อความธรรมดา

**ข้อจำกัดที่ควรรู้:** โปรโตคอล RTSP ของกล้องเกือบทุกยี่ห้อไม่เข้ารหัสวิดีโอ ภาพจึงวิ่งใน Wi-Fi บ้านแบบไม่เข้ารหัส
(การ login ใช้ digest ถ้ากล้องรองรับ) — ใช้รหัส Wi-Fi ที่แข็งแรง (WPA2/WPA3) และแยกกล้องไว้เครือข่าย Guest/IoT ถ้าเราเตอร์ทำได้

### ดูนอกบ้าน
**อย่าเปิด port forward** ที่เราเตอร์ ให้ใช้ VPN เข้าบ้านแทน เช่น WireGuard บนเราเตอร์ หรือ Tailscale
(subnet router) แล้วแอปจะใช้ IP เดิมของกล้องได้เลย

### ตั้งกุญแจเซ็นแอป (ทำครั้งเดียว แนะนำ)
ถ้าไม่ตั้ง CI จะเซ็นด้วยกุญแจชั่วคราว ทำให้ติดตั้งเวอร์ชันใหม่ทับไม่ได้ (ต้องถอนก่อน ข้อมูลกล้องหาย)
```bash
keytool -genkeypair -v -keystore homecam.jks -alias homecam -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 homecam.jks   # คัดลอกผลลัพธ์
```
GitHub → Settings → Secrets and variables → Actions เพิ่ม:
`HOMECAM_KEYSTORE_B64`, `HOMECAM_KEYSTORE_PASSWORD`, `HOMECAM_KEY_ALIAS` (= `homecam`), `HOMECAM_KEY_PASSWORD`
และเก็บไฟล์ `homecam.jks` ไว้ที่ปลอดภัย **อย่า commit เข้า repo**

## โค้ด
| ไฟล์ | หน้าที่ |
|---|---|
| `CameraStore.java` | เก็บรายการกล้องแบบเข้ารหัส + กุญแจ Keystore ผูกกับการยืนยันตัวตน |
| `App.java`, `BaseActivity.java`, `LockActivity.java` | ล็อกแอป, BiometricPrompt, FLAG_SECURE |
| `NetGuard.java` | อนุญาตเฉพาะที่อยู่ในเครือข่ายบ้าน/VPN |
| `Onvif.java` | ค้นหากล้อง (WS-Discovery) และดึงลิงก์ RTSP |
| `LiveStream.java` | เล่น RTSP ด้วย Media3/ExoPlayer หน่วงต่ำ ต่อใหม่อัตโนมัติ |
| `Brands.java` | ค่าตั้งต้น path ของแต่ละยี่ห้อ |
